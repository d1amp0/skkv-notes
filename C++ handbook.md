### Спецификаторы/Ключевые слова
`const`, `consexpr`, `inline`, `restrict`,  `mutable`, `static`, `extern`, `explicit`, `volatile`, `virtual`, `override`, `final`, `friend`
#### `const`
Константная переменная/константный указатель/константный метод класса
#### `constexpr`
функция/переменная, значение которой можно вычислить на этапе компиляции, в них могут быть использованы только `constexpr` значения
#### `inline`
Используется для `static` полей и методов классов, [[C++ modern features#`inline`|подробнее]]
#### `restrict`
В C++ решили избавиться от этого слова, но оно до сих пор выживает под покровом компиляторо-зависимых слов (например, `__restrict`). [[Variables and structures#`restrict`|В Си]]
#### `mutable`
Может быть использовано для:
1. Поля класса, тогда это поле можно менять даже в `const` методах
2. [[C++ modern features#`mutable` у лямбды|В лямбде]]
#### `static`
Может быть использовано для:
1. Глобальных функций/переменных, чтобы их не было видно снаружи (C-style)
2. Локальных переменных, чтобы сделать их "глобальными"
3. `static` полей и методов
#### `extern`
Для добавления внешней глобальной переменной без её создания (как шапка функции без тела)
#### `explicit`
Перед конструктором от одного аргумента для отключения неявного преобразования
#### `volatile`
Указание на то, что переменная может быть изменена по независящим от компилятора причинам, из-за этого отключаются некоторые оптимизации
#### `virtual`
Перед виртуальным методом (лучше писать только в базовом, при переопределении лучше использовать `override`). [[C++ inheritance#Виртуальные функции|Подробнее]]
#### `override`
Показывает, что этот метод - переопределение метода базового класса
#### `final`
Запрещает дальнейшее переопределение
#### `friend`
"Другом" можно сделать класс/оператор/функцию, это даёт "другу" доступ ко всем полям/методам
