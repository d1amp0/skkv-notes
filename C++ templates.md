--------------------------------------------------------------------------------

Шаблоны позволяют писать код, который компилятор потом порождает для конкретных типов. Это не макросы: шаблоны знают типы и проверяются компилятором.

--------------------------------------------------------------------------------
## Шаблоны функций

Простой пример:

```cpp
template <typename T>
T max_value(T a, T b) {
    return a > b ? a : b;
}
```

Теперь можно вызвать:

```cpp
int x = max_value(1, 2);
double y = max_value(1.5, 2.5);
```

Компилятор создаст отдельную версию функции для `int` и отдельную для `double`.

--------------------------------------------------------------------------------
## Выведение типа шаблона

В вызове:

```cpp
max_value(1, 2);
```

компилятор видит два `int`, поэтому `T = int`.

А здесь уже проблема:

```cpp
max_value(1, 2.5);
```

Первый аргумент `int`, второй `double`. Один `T` вывести не получается однозначно.

Компилятор не выбирает автоматически "ну пусть будет double" для такого шаблона. Он видит противоречие:

- из первого аргумента получается `T = int`;
- из второго аргумента получается `T = double`.

Поэтому вызов не скомпилируется примерно с ошибкой вида:

```text
no matching function for call to max_value(int, double)
deduced conflicting types for parameter T
```

Можно указать тип явно:

```cpp
max_value<double>(1, 2.5);
```

Тогда оба аргумента будут приведены к `double`.

--------------------------------------------------------------------------------
## Несколько параметров шаблона

Можно завести несколько типов:

```cpp
template <typename T1, typename T2>
auto mul(T1 a, T2 b) {
    return a * b;
}
```

Здесь результат зависит от выражения `a * b`. Поэтому удобно использовать `auto` для возвращаемого типа.

--------------------------------------------------------------------------------
## Шаблоны классов

Шаблонным может быть не только функция, но и класс:

```cpp
template <typename T>
struct Box {
    T value;
};

Box<int> a{5};
Box<double> b{3.14};
```

`Box<int>` и `Box<double>` — это разные типы.

--------------------------------------------------------------------------------
## Специализация

Иногда для конкретного типа нужна отдельная реализация:

```cpp
template <typename T>
struct Printer {
    static void print(const T &x) {
        // обычная печать
    }
};

template <>
struct Printer<bool> {
    static void print(bool x) {
        // особая печать bool
    }
};
```

Это называется специализация шаблона.

Специализация бывает неполной, можно уточнить тип, например:
```cpp
template<typename T>
void info(T val) {
    std::cout << "T\n";
}

template<typename T>
void info(T* ptr) {
    std::cout << "T*\n";
}
```

Тогда если тип подходит под уточнённый, то будет выбран именно он.

--------------------------------------------------------------------------------
## Почему шаблоны часто пишут в заголовках

Шаблон — это инструкция для компилятора, как породить код для конкретного типа. Чтобы породить `Box<int>` или `max_value<double>`, компилятор должен видеть тело шаблона.

Это именно инструкция для компилятора, он ещё ничего не знает о других файлах, линковка - 2й этап.

Поэтому шаблоны часто (почти всегда) целиком лежат в `.h`/`.hpp`-файлах.

Если спрятать тело шаблона только в `.cpp`, другой файл может не суметь породить нужную версию.
